Line balancing to takt, step by step

LeanPro Academy knowledge library

Line balancing spreads work evenly across stations so that each one can finish within takt time, the pace the customer needs.

First, calculate takt time: available working time divided by customer demand. Then break the job into small work elements and time each one with a stopwatch over several cycles.

Draw a bar for each station showing its total work content, with a line at takt time. Stations above the line are bottlenecks; stations far below it are waiting.

Move elements from overloaded stations to underloaded ones, respecting the order in which work must be done. Remove waste such as walking and searching before moving work, because removing waste is cheaper than moving it.

When the line is balanced, write it into standard work so each operator knows exactly what to do within the takt.
